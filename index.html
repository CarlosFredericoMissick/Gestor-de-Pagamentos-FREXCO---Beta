Formato — Planilha de CNPJs/PIX

4 colunas, sem cabeçalho obrigatório

A — ID Motorista B — Nome C — CNPJ D — Chave PIX
42 Ademário 12.345.678/0001-90 12.345.678/0001-90
228 Adilson Costa 37.148.610/0001-47 1998706-0403
  • • Coluna A deve conter o ID Motorista (driver_id) — o mesmo da base de motoristas
  • • A Chave PIX pode ser CNPJ, telefone, e-mail ou chave aleatória
  • • Linhas sem CNPJ e sem PIX são ignoradas
  • • Um motorista pode ter múltiplas linhas (múltiplos CNPJs)

Formato — ZIP de Contratos

Arquivos PDF dentro de um .zip

Padrão do nome de cada arquivo:

contrato_{ID Motorista}_{Nome}.pdf
Exemplo de nome do arquivo Driver ID Motorista
contrato_42_Ademário.pdf 42 Ademário
contrato_228_Adilson Costa.pdf 228 Adilson Costa
  • • O ID Motorista é o driver_id da base de motoristas
  • • O nome após o ID é apenas para identificação visual — não é usado no matching
  • • Arquivos que não seguirem o padrão contrato_{número}_*.pdf serão reportados como não encontrados
  • • O ZIP pode conter subpastas — os arquivos são localizados independente da estrutura
